SIMULAÇÃO 8: MODULAÇÃO ANGULAR — EQUIVALÊNCIA FM & PM

Geração Indireta e Relações Fundamentais: Integrador + Modulador PM → FM • Diferenciador + Modulador FM → PM

Simulação 8
Diagramas de Blocos & Demonstração Formal
Demonstração Formal: O sinal integrado é x(t) = ∫₀ᵗ m(τ) dτ. Ao alimentar o modulador de fase (PM) de sensibilidade k_p, o sinal de saída é s(t) = A_c cos[2π f_c t + k_p ∫₀ᵗ m(τ) dτ]. Sua frequência instantânea é f_i(t) = (1/2π) dθ/dt = f_c + (k_p / 2π) m(t). Fazendo k_p = 2π k_f, temos f_i(t) = f_c + k_f m(t), que é identicamente a expressão de um modulador FM direto.
Demonstração Formal: O sinal diferenciado é y(t) = dm(t)/dt. Ao alimentar o modulador de frequência (FM) de sensibilidade k_f, o desvio de fase de saída é φ(t) = 2π k_f ∫₀ᵗ (dm/dτ) dτ = 2π k_f [m(t) - m(0)]. Assumindo referência m(0) = 0, temos s(t) = A_c cos[2π f_c t + 2π k_f m(t)]. Fazendo 2π k_f = k_p, temos s(t) = A_c cos[2π f_c t + k_p m(t)], que é identicamente a expressão de um modulador PM direto.

Análise Didática do Enunciado & Caso Senoidal vs Caso Geral

O enunciado traz: "a) FM alimentado por ∫m → fase proporcional a ∫∫m ... modular m(t) em fase" e "b) PM alimentado por dm/dt → f_i proporcional a m(t)", finalizando com a solicitação dos diagramas: (integrador + modulador PM → FM; diferenciador + modulador FM → PM).

  • Para qualquer sinal arbitrário m(t): As relações universais da literatura clássica (Lathi, Haykin) são exatamente as expressas entre parênteses: Integrador + PM → FM e Diferenciador + FM → PM.
  • Para um tom puro senoidal m(t) = A_m cos(ω_m t): Uma dupla integração resulta em ∫∫ cos(ω_m t) dt² = -(1/ω_m²) cos(ω_m t) ∝ -m(t). Da mesma forma, a derivada segunda é d²m/dt² = -ω_m² cos(ω_m t) ∝ -m(t). Por isso, exclusivamente para senoides, a forma de onda do sinal integrado duas vezes preserva a mesma frequência do sinal original.

Nossa simulação abaixo permite escolher senoidal, triangular ou quadrada para comprovar numericamente a perfeita equivalência em ambos os casos!
